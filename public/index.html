Giải Quyết Vấn Đề Bằng Điểm (Tie-Breaking Algorithm)

Ứng dụng kỹ thuật Fractional Timestamp Score trong Redis

📐 Công Thức Tính Điểm Thập Phân:
Final Score = Điểm Gốc + (1 - (Timestamp / 10^14))

👉 Người đạt điểm trước có Timestamp nhỏ hơn → Phần thập phân lớn hơn → Xếp hạng trên!

Trực Quan Hóa Thuật Toán Skip List (Danh Sách Nhảy)

Bản chất cấu trúc giải thuật giúp Redis đạt tốc độ O(log N) thay vì O(N) của SQL

Level 4 (Express Lane):
HEAD ─────────────── 50,000 ─────────────── 100,000 ─────────────── NIL
Level 3:
HEAD ─────── 25,000 ─────── 50,000 ─────── 75,000 ─────── 100,000
Level 2:
HEAD ─── 12,500 ─── 25,000 ─── 50,000 ─── 62,500 ─── 75,000
Level 1 (All 100k items):
HEAD ─ ... ─ 5,338 ─ 5,339 (ĐÍCH ĐẾN) ─ 5,340 ─ ...
📊 So Sánh Hiệu Năng Giải Thuật Giữa Redis & SQL:
Tiêu Chí So Sánh SQL Truyền Thống (Table Scan / B-Tree) Redis NoSQL (Skip List + Hash Table)
Độ Phức Tạp Tra Cứu Rank O(N) - Quét toàn bộ dòng O(log N) - Nhảy tầng
Số bước tìm vị trí #5,339 5,339 bước tuần tự ~14 bước nhảy
Tốc Độ Thực Thi 150 - 500 ms (Nghẽn đĩa) 0.15 ms (Sub-millisecond)

🎯 Hướng dẫn thực hiện bài test "Mất điện" trước giảng viên:
  1. Bấm nút BGSAVE ở trên để Redis chốt file dump.rdb.
